Health Transformation Lab · Evidence you can check

Synthetic patient records

John Bowyer · personal project, not affiliated with any organization

In fifteen days, one person working with a cloud coding agent took a health-data repository from nothing to 960 commits and 2,269 tests, without typing code. This deck asks what a small model, one that runs on a single GPU, can take out of that loop. The answer comes with a task set anyone can use: 93 real changes from that repository, each verified by the competition's own evaluator, which is its scoring program. Every patient record in the repository is synthetic. This is a personal project, not any organization's plan.
