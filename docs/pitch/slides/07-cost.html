Sources: the README, "Cost, and what it means for decisions", and the paper, Section 6. Rental figures are estimates, not money spent

Each run recorded its own GPU time. One full run of the 93 tasks took about 2 GPU-hours on one A100, 3.3 to 3.6 on one L4, and 7.7 to 9.0 on four L4s, which is the competition's own setup. At median rental prices that is an estimated 3.50 to 3.76 US dollars, 2.74 to 3.01, and 6.37 to 7.50. Nothing was paid by the hour: Kaggle's GPUs were free within a weekly allowance, and Colab is a subscription. Four L4s finished a task about as fast as one A100, so for a run of your own one GPU is enough. Each machine ran in its own session, once for each arm, so read these as what happened and not as a benchmark of the machines. From the timing records, 66 to 83 percent of a task's time was the model's own calls, 14 to 15 percent was summarising older turns, and the graph tools took under 0.1 percent. On the first baseline, the 13 clearly described tasks cost 0.38 hours of agent time a fix, against 1.80 over all 48. So three decisions follow: rent one GPU, check task descriptions before paying to run them, and speed up the model's own calls first. That performance work comes next; none of it has been done or measured.
